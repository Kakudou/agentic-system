# Final-Stop Checklist

Mark every item before issuing a `ready-for-human-submission` handoff.

- [ ] Written reporting authorization and current scope are referenced.
- [ ] The report and every included evidence reference are admitted.
- [ ] Supplied policy/format requirements are mapped with no unresolved blocker.
- [ ] Sensitive or uncertain content is omitted, metadata-only, or reviewer-approved redacted.
- [ ] The exact package identifier, submitter, and permitted channel are recorded.
- [ ] Explicit final authorization covers that exact package and recipient.
- [ ] The handoff states that no submission, upload, verification, or messaging occurred.

If any item is unchecked, stop and issue `not-ready` or `stopped` with the missing decision.
