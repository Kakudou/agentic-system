# Confidence and Conflict Matrix

| Evidence condition | Confidence | Required handling |
| --- | --- | --- |
| Current, direct, target-specific evidence corroborated by an independent permitted source | High | State the layer limitation and retain both source locators. |
| One current direct observation clearly mapped to the target | Moderate | Record alternatives and request corroboration before escalation. |
| Indirect, historical, third-party, or ambiguous indication | Low | Phrase as a hypothesis; do not prioritize active work from it alone. |
| Missing, out-of-scope, sensitive, or materially conflicting evidence | Unknown | Do not claim attribution. Stop or hand off the unresolved gap. |

| Conflict | Control |
| --- | --- |
| Different evidence names different technologies | Preserve both; do not select a winner without permitted corroboration. |
| Evidence may be generated by a proxy, cache, or embed | Attribute only to the observed layer. |
| Evidence maps to a different host, environment, or date | Keep it separate; do not combine it into the target claim. |
| Evidence requires unsafe retention or sharing | Redact, use an approved secure reference, or mark the claim unknown. |
