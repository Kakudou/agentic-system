# Input Observation

## Purpose

Collect a minimal, attributable record of inputs produced during ordinary, authorized use.

## Preconditions

Read [scope and request-contract baseline](scope-contract.md). Use an approved test account and a client state that matches the contract.

## Method

Navigate permitted UI flows normally, or review already captured allowed client traffic and first-party documentation. For each request, record endpoint, method, source action, input location, name/path, value shape, and source locator. Observe only the traffic naturally generated by the approved flow.

## Interpretation And Controls

UI labels, JavaScript identifiers, response keys, and analytics events are leads, not confirmed request inputs. Do not replay requests, change request data, click irreversible controls, or follow out-of-scope links. Redact secrets and personal data at capture time.

## Evidence And Handoff

Complete one worksheet row per candidate and use [validation and handoff](validation-handoff.md) to state confidence and exclusions.
