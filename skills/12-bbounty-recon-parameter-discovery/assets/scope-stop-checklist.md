# Scope And Stop Checklist

- [ ] Official authorization or policy reference is recorded.
- [ ] Target, endpoint, methods, client/account state, and observation window are in scope.
- [ ] No request mutation, guessing, fuzzing, enumeration, replay, or automation is planned.
- [ ] Sensitive values will be redacted and not retained in the inventory.
- [ ] Cross-origin, third-party, and redirect destinations are excluded unless explicitly authorized.
- [ ] Stop if ownership, scope, action safety, data sensitivity, or request-contract terms are unclear.
- [ ] Record the stop reason and escalation route before handing off.
