## Compact Foundation

### Type, Spacing, Shape, and Surfaces

- **[DR]** UI documentation assigns Geologica to headings and IBM Plex Sans to body/UI roles. Source: [Typography](https://filigranhq.github.io/filigran-ui/docs/2-typography).
- **[DR]** Documented spacing is `2`, `4`, `8`, `12`, `16`, `24`, and `32px`. Source: [Spacing](https://filigranhq.github.io/filigran-ui/docs/3-spacing).
- **[IE]** An extended implementation spacing scale exists in [`theme.css`](https://github.com/FiligranHQ/filigran-ui/blob/860a13c2e12eb01c490936ce871ada08fcba9ec3/packages/filigran-ui/src/theme.css).
- **[IE]** Radius treatment is restrained: base `4px`, xs `2px`, with pill/full available. Layered surfaces and subtle/default/strong borders express hierarchy. Source: [`theme.css`](https://github.com/FiligranHQ/filigran-ui/blob/860a13c2e12eb01c490936ce871ada08fcba9ec3/packages/filigran-ui/src/theme.css).
- **[IA]** Preserve rhythm and restrained geometry, but enlarge scale and spacing for the static medium; do not copy compact UI dimensions blindly.

| Surfaces/layout | [Card](https://filigranhq.github.io/filigran-ui/docs/components/card), [Separator](https://filigranhq.github.io/filigran-ui/docs/components/separator) | Cards become content panels; separators and layers organize reading order. |

- **[IE]** Exported but undocumented components may be found in client/server barrels. Treat them as volatile implementation evidence, not style law; verify them at the pinned source before use.
- **[IA]** Static translations: cards → content panels; badges → metadata/status chips; dialogs/toasts → warnings or decisions; tabs → clear static section labels. Remove hover, focus, pressed, cursor, and false-clickability cues.

## Loader and Skeleton

- **[IE]** [FiligranLoader docs](https://filigranhq.github.io/filigran-ui/docs/components/2-filigran-loader) describe branded loading-state motion, but the actual import at the snapshot is `@filigran/icon`; docs prose incorrectly says `@filigran/ui`.
- **[IE]** [`FiligranLoader.tsx`](https://github.com/FiligranHQ/filigran-ui/blob/860a13c2e12eb01c490936ce871ada08fcba9ec3/packages/filigran-icon/custom/FiligranLoader.tsx) uses a `150×150` viewBox, `currentColor`, and a `2.5s` linear infinite animation with no built-in reduced-motion handling.
- **[IA]** Treat it only as branded loading-state motion, not as a static logo or general corporate motif. Motion delivery is outside scope. In static media use an approved static mark; never freeze an arbitrary incomplete animation frame.
- **[IE]** The inspected [Skeleton](https://filigranhq.github.io/filigran-ui/docs/components/skeleton) behavior is a distinct generic content placeholder. Do not conflate it with `FiligranLoader`.
