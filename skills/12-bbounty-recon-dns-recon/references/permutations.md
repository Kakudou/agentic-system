# Name-Pattern Scope Controls

## Purpose and Preconditions

Use this reference when a proposed name pattern appears in engagement material. It prevents a pattern from becoming unbounded discovery work.

## Guidance

Only observe a name when it is individually named in scope, supplied by the owner, or already present in a permitted passive source. Similarity to a known name, environment label, or naming convention does not authorize generating or testing alternatives. Record the source and scope basis for every observed name.

## Limits and Handoff

Do not create permutations, wordlists, mutation rules, or automation. If name coverage appears incomplete, request an expanded signed scope or an owner-provided inventory. Document the gap and stop rather than inferring permission.
