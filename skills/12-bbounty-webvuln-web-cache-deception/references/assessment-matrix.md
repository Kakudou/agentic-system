# Cache Deception Assessment Matrix

| Check | Controlled evidence needed | Interpretation | Required action |
|---|---|---|---|
| Layer identified | Owner documentation or telemetry | Baseline is attributable | Continue within scope |
| Dynamic route non-shared | Policy and cache decision | Expected safe behavior | Record and close |
| Path interpretation differs | Origin and edge route evidence | Hypothesis only | Apply confirmation controls |
| Controlled response stored unexpectedly | Marker plus cache telemetry | Controlled finding | Cleanup and owner escalation |
| Non-controlled data appears | Minimal observation | Safety boundary crossed | Stop immediately |

Use the workflow's linked guides for methodology, evidence, and remediation.
