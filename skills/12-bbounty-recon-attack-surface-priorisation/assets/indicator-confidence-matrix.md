# Indicator-Confidence Matrix

| Indicator class | Admissible support | Confidence guidance | Common confounders | Handoff requirement |
| --- | --- | --- | --- | --- |
| Documented service or interface | Program-provided document or approved linked source | Direct when explicit and dated | Stale version, environment mismatch | Cite document and date |
| Approved inventory membership | Attributable inventory within engagement window | Direct when exact asset matches | Alias, tenant, or ownership ambiguity | Preserve asset identifier and context |
| Normal client-visible entry point | Approved ordinary client record | Direct for the observed context only | Cached content, third-party component | State client, date, and context |
| Ownership or lifecycle status | Explicit program statement | Direct when scope is exact | Reorganization, inherited branding | Cite statement; mark currency limits |
| Conflicting or incomplete record | Any admitted record lacking decisive context | Inconclusive | Copied data, stale material, missing scope | State alternatives and needed decision |

Indicators describe observed records. They do not imply a weakness, access path, security impact, or permission for further activity.
