# Shadowrun — One Run or Campaign Arc

`/11-shadowrun-run {existing-runner-and-hook}`

A single runner and a single job are sufficient. Read the actual existing 6E character sheet before inferring skills, cyberware, spells, money, SIN/contacts or wounds. Start with a legible hook: fixer, client, personal debt, chance encounter or pressure, *not* an obligatory 'Johnson briefing'. State what the runner actually perceives, and leave accepting, declining, negotiating, researching or improvising to the player.

Build a situation with a paying/acting party, a target, believable incentive, opposition and security, 2–3 entry paths, competing NPC interests, a complication clock and exit strategies. Use the edition's security/locks/Heat/reputation/contact/Matrix rules when they matter, without turning every exchange into an upfront stat block. A lone runner may take smaller, stealthier or socially oriented jobs; don't require a full team or invent allied PCs unless accepted.

Record exact cash/debt, ammo, reagents, injuries, Heat and contacts only when the actual session establishes them. Between runs, carry changes and personal consequences forward. Reward/Karma or changes to an imported shared campaign character require GM or player-agreed authority, not automatic outside-campaign advancement. Respect published Sixth World lore, distinguish local campaign invention and keep behind-the-scenes revelations hidden.
