# Review Handoff Template

```yaml
triage_preparation_handoff:
  report_id: ""
  authorization_reference: ""
  reviewer: ""
  approved_evidence_location: ""
  scope_status: in_scope | unclear | stopped
  triage_record_reference: ""
  requests:
    - request_id: ""
      classification: clarification | status_notice | duplicate_or_merge_notice | severity_or_impact_question | closure_notice | unclassified
      quoted_request_reference: ""
      factual_points: []
      evidence_references: []
      confidence: direct | corroborated | inconclusive | unsupported
      limitations: []
      reviewer_decision_needed: ""
  redactions_or_withheld_material: []
  stop_events: []
  requested_decision: ""
```

This template supports internal review only. It is not an external message or a platform action.
