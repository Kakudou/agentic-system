# Privacy And Stop Checklist

- [ ] Authorization, scope, source provenance, and handling rules are known.
- [ ] Each factual point has an evidence reference or is labeled unsupported.
- [ ] Credentials, tokens, cookies, personal data, session material, and internal-only identifiers are removed or held in an approved location.
- [ ] Material uncertainty, contradictions, and missing context are disclosed.
- [ ] No platform access, message sending, active retesting, negotiation, or report-state change is included.
- [ ] A reviewer and requested decision are identified.
- [ ] Stop and hand off if authority, sensitivity, scope, or evidentiary support is unclear.
