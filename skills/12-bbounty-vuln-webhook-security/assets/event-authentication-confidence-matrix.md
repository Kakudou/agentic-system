# Event And Authentication Confidence Matrix

| Evidence state | Permitted conclusion | Confidence | Required control |
| --- | --- | --- | --- |
| Owner documentation names a control | Control is documented | medium | Mark enforcement unverified |
| Approved capture shows a redacted control indicator | Control indicator was observed | medium | Do not infer validation outcome |
| Documentation and approved evidence align | Boundary is consistently described | high | Keep implementation verification owner-led |
| Partial, conflicting, or unattributed evidence | Boundary is unknown or inconclusive | low | Escalate or stop |

Never infer sender authenticity, freshness enforcement, duplicate rejection, or impact from a field alone.
