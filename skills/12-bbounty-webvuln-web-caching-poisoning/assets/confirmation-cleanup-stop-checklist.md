# Confirmation, Cleanup, And Stop Checklist

- [ ] Scope explicitly covers the endpoint and one variation dimension.
- [ ] Fixture, account, and marker are controlled, inert, and reversible.
- [ ] No forwarding/security header, request body, or unapproved input was varied.
- [ ] Cache and origin telemetry corroborate the observation.
- [ ] Browser state, experiments, replication, and deployment changes were excluded.
- [ ] Marker removed and cache invalidation confirmed or requested.
- [ ] Testing stopped after confirmation or ambiguity.
- [ ] Owner was notified if non-controlled content or unexpected partitioning appeared.
