# Cache Key Integrity Assessment Matrix

| Check | Controlled evidence needed | Interpretation | Required action |
|---|---|---|---|
| Layer/key map available | Owner documentation or telemetry | Assessment attributable | Continue within scope |
| Approved variation is keyed | Fixture and telemetry agree | Expected partitioning | Record and close |
| Variation/key behavior diverges | Origin and cache evidence | Hypothesis only | Apply confirmation controls |
| Controlled marker crosses partition unexpectedly | Telemetry plus fixture evidence | Controlled configuration gap | Cleanup and owner escalation |
| Non-controlled content appears | Minimal observation | Safety boundary crossed | Stop immediately |

Use the workflow's linked guides for methodology, evidence, and remediation.
