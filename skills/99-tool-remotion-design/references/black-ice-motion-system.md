# Black-Ice Motion System

Use only for unspecified visual choices. This is a launch system, not a mandatory skin.

## Intent
Terminal noir, decker cartography, hostile network space, illicit infrastructure, worn technical surfaces, analog intervention over digital systems, urban systems under pressure, cybernetic ritual, precise information with slight human damage. Intelligent, dangerous, tactile, authored.

## Avoid
Vaporwave, synthwave, default cyan/magenta, neon-city B-roll, constant glitch, code rain, random hex, fake terminal commands, generic HUD reticles, gratuitous circuits, chrome sci-fi, purple fog, every object glowing.

## Palette foundation
Black Ice `#0B0E11`; Carbon `#151A1F`; Dead Paper `#D6D1C7`; Cold Steel `#7F8B94`; Burned Amber `#C58A3A`; Oxide Teal `#3E7C74`; Dried Blood `#A34A46`.

Unlike Excalidraw, the palette is permeable. Introduce brand/scientific/lore/photographic colors when stronger. Never sacrifice the subject to the default palette.

## Materials
Choose one or two: matte black, oxidized metal, photocopy, CRT phosphor, terminal glass, scratched acetate, scanline texture, thermal paper, graphite, stamped labels, low-bit transmission artifacts, cable traces, concrete, weathered paint.

## Motion vocabulary
Possible: system wake-up, acquisition, route discovery, clipped reveal, redaction/disclosure, type resolving from signal damage, slow drift, layered parallax, focus handoff, threshold crossing, diagram-to-world transform, transmission loss, brief chromatic separation, spatial interface fragments, data pulse, analog marks over precise geometry, controlled corruption, reconstruction.

Use only what supports meaning.

## Glitch
Glitch can mean intrusion, contradiction, instability, corruption, hidden data, layer transition, system failure, reality boundary. Keep brief, motivated, readable, and rare.

## Creative freedom
2D, SVG, Canvas, WebGL, 3D, particles, photography, footage, procedural graphics, shaders, maps, diagrams, audio-reactivity, typography, character art, documentary editing, abstract motion, brutal minimalism, dense collage are all valid. Source determines language.

## Ōtsumi trace
Prefer diegetic forms: final system message, closing annotation, terminal credit, quiet footer, post-action status. Format `<work-specific punchline> — Ōtsumi`; brief, unique, subordinate; omit for white-label.
