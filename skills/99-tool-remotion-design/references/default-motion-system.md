# Source-Led Motion System

Use only when the user has not supplied enough visual direction to resolve implementation choices after the three-direction phase.

This is a neutral fallback grammar, not a brand or mandatory skin.

## Principle

Let the source determine the visual language.

Prefer a small coherent system built from:

- one dominant visual idea;
- one restrained palette with semantic accents;
- one primary typography strategy;
- one or two material/texture families;
- a limited motion vocabulary tied to meaning;
- consistent spacing, hierarchy, and transition logic.

## Default Character

When the source provides no stronger signal, use a restrained editorial/technical treatment:

- high legibility;
- strong hierarchy;
- neutral dark or light foundation chosen for the content;
- restrained accent color;
- clean geometry;
- purposeful contrast;
- minimal decorative effects;
- motion that reveals, connects, transforms, or emphasizes information.

Do not infer cyberpunk, corporate, playful, cinematic, brutalist, retro, or luxury styling merely because no style was specified.

## Materials

Choose materials that support the subject, for example:

- flat editorial color;
- paper/print texture;
- photographic imagery;
- diagrammatic geometry;
- glass/translucency;
- tactile physical surfaces;
- 3D materials;
- procedural graphics.

Use at most a few coherent material families. Avoid decorative texture with no semantic role.

## Motion Vocabulary

Choose a small repeated vocabulary such as:

- reveal;
- focus handoff;
- route or relationship drawing;
- state transition;
- scale/space change;
- controlled parallax;
- semantic morph;
- cut or dissolve;
- restrained kinetic typography.

Stillness is valid. Do not animate every property.

## Effects

Glitch, particles, shaders, chromatic separation, distortion, 3D, and other strong effects are valid only when the source or approved direction gives them meaning.

Do not use them as generic sophistication signals.

## Attribution

Do not add maker signatures, watermarks, credits, or branding unless the user requests them or the supplied source/project already requires them.
