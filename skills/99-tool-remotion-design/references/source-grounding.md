# Source Grounding

Use during `GROUND` and `MODEL`. Temporal design amplifies claims; never let animation make unsupported material look certain.

## Truth hierarchy
1. explicit user instructions
2. user-provided sources
3. inspected project files/compositions
4. authoritative sources deliberately retrieved
5. high-confidence general knowledge only when knowledge-assisted work is allowed

User instructions govern objective/style; evidence governs facts.

## Evidence ledger
Maintain: item, evidence/path, class (`explicit`/`derived`/`uncertain`), confidence, planned use. Explicit and defensible derived content may appear normally. Uncertain material must be qualified or omitted. Never infer causation from sequence, invent missing chronology, or convert approximate values to precise numbers.

## Repository inspection
Inventory relevant files; inspect manifests, README/docs, entrypoints, configuration, domain files, and user keywords; follow references only when material; exclude generated/vendor/cache output unless relevant; record inspected versus uninspected scope. Do not claim full-repository analysis when only a subset was read.

## Existing Remotion project
Inspect package versions, composition IDs, registrations, props/schemas, tokens, timing constants, assets, fonts, audio, Player integrations, render scripts, and existing formats. Preserve stable IDs unless approved architecture requires replacement.

## Domain safeguards
- Code: verify runtime/data/build/deployment relationships separately.
- Science/chemistry: preserve notation, units, states, directionality, conditions, uncertainty; label teaching simplification.
- Books/research/lore: distinguish source fact, author claim, event, interpretation, rumor, speculation; verify quotations.
- Data: validate provenance, shape, ranges, missing values; distinguish observed/calculated; do not interpolate merely for prettier motion unless allowed.

## Asset truth
For each image/video/audio/font/map/resource record real path/URL, availability, provenance, metadata, final/placeholder status, and usage limits. Never invent an asset.

## Clarification threshold
Ask only when competing objectives materially change output, audience is missing and changes abstraction, sources irreconcilably conflict, essential assets are inaccessible, sensitive material may be exposed, or scope cannot be made usable. Otherwise state assumptions and continue.
