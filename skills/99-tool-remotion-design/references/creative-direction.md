# Creative Direction

Generate three different answers, not three skins.

Each direction defines creative thesis, audience experience, output package, narrative structure, temporal grammar, visual language, typography, edit/camera language, audio, technical architecture, reusable/parameterized elements, serendipity move, risks, tradeoff, and source-specific rationale.

Every pair must differ on at least three: narrative structure, temporal rhythm, visual abstraction, editing grammar, camera behavior, typography, audio strategy, interaction, technical architecture, density, emotional register, output package.

Explore axes such as linear explanation/reveal/transformation/investigation/loop/escalation/contrast; typography-led/diagrammatic/cinematic/mixed-media/interface/symbolic/data/3D/photographic; patient/surgical/percussive/fragmented/continuous/chaptered; static/drift/traversal/object-follow/parallax/no-camera; silent/score/ambience/voice/percussion/diegetic/audio-reactive.

## Serendipity
Ask: what can time/React/rendering do that the source did not explicitly request but that makes the idea clearer, more memorable, or emotionally accurate? The experiment must be source-specific, reversible, isolated, deterministic, previewable, readable.

## Risks
Name real risks: unavailable assets, render cost, 3D complexity, font/license constraints, codec/alpha requirements, Player-vs-render differences, uncertain data, voice/audio dependency, platform safe areas, native/browser dependencies. Do not label ordinary development as risk.

## Reject before critique if
It fits any unrelated brief after renaming, cyberpunk styling does all the work, motion is only entrance effects, serendipity is generic glitch, unverified assets are required, audience experience is unclear, architecture is oversized, or tradeoff is vague.
