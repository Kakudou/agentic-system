# Scope And Stop Checklist

- [ ] Written authorization and engagement reference are recorded.
- [ ] Application asset is explicitly in scope.
- [ ] Permitted evidence sources and low-impact methods are known.
- [ ] Application ownership is supported independently of provider markers.
- [ ] Edge, origin, provider, and tenant boundaries are identified.
- [ ] Evidence has source, time, asset, method, and secure reference.
- [ ] No origin access, alternate routing, bypass, discovery, enumeration, or automation is planned.
- [ ] Stop contact and remediation recipient are named.
- [ ] Work stops for scope conflict, ownership uncertainty, sensitive data, or any unexpected third-party boundary.
