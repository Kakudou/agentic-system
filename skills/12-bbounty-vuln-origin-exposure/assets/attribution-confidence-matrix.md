# Attribution-Confidence Matrix

| Evidence state | Allowed interpretation | Attribution confidence | Required action |
| --- | --- | --- | --- |
| No admitted evidence or out-of-scope asset | No assessment | none | Stop and clarify scope. |
| One edge marker or routing indicator | Delivery context only | unverified | Record alternatives; do not infer origin control. |
| Corroborated application ownership and documented edge model | Architecture context | likely | Request owner-side configuration review. |
| Owner inventory confirms application, edge, and origin responsibility | Owner-verifiable concern | confirmed | Hand off for internal ingress and routing validation. |
| Provider, customer, tenant, or conflicting ownership evidence | Third-party boundary | third_party | Stop; report only the boundary rationale. |
