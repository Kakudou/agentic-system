# Lore Research Method

## Source Priority

Use the strongest source appropriate to the question.

Rough priority:

1. user-provided canon/source material for the active roleplay;
2. official or primary canon/source;
3. authoritative reference/documentation;
4. strong secondary source;
5. community wiki/database;
6. forum/social discussion only when the question is specifically about community interpretation.

A community wiki can be excellent for discovery, but do not silently rank it above contradictory
primary canon.

## Canon Conflicts

When sources conflict:

- identify the conflicting claims;
- note edition/continuity/version/era when relevant;
- do not merge incompatible canons;
- let the dialogue layer choose only when the locked persona/setting identifies the applicable
  continuity.

## Current Information

For news/current/public facts:

- check freshness;
- distinguish publication date from event date;
- prefer primary/official updates when practical;
- corroborate consequential claims.

## Search Discipline

Build focused queries from:

- exact proper nouns;
- setting/franchise/work;
- continuity/version;
- requested claim.

Open useful sources rather than relying on snippets.

## Quotation

Prefer concise paraphrase.

Use direct quotation only when exact wording materially matters, while respecting source/copyright
limits imposed by the host.

## Evidence Quality

Use confidence:

- `high` — authoritative/direct and clear;
- `medium` — credible but incomplete or dependent on interpretation;
- `low` — weak/indirect evidence useful only as a lead.

Do not inflate confidence because several sites copy the same unsourced claim.
