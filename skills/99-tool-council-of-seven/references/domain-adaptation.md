# Domain Adaptation

The seven lenses stay fixed. Apply them to the artifact's actual domain.

## Code / Software

- Skeptic: bugs, security, races, edge cases.
- Architect: interfaces, coupling, state, boundaries, dependencies.
- Minimalist: duplication, abstraction overhead, unnecessary dependencies.
- Context Scout: platform standards, idioms, established patterns.
- Aesthetician: API ergonomics, naming, developer/user experience, clarity.
- Economist: maintenance, runtime/infra cost, delivery complexity.

## Architecture / Operations

- Skeptic: failure domains, hazards, hidden dependencies.
- Architect: topology, ownership, data/control flow, interfaces.
- Minimalist: needless services/layers, over-decomposition.
- Context Scout: established operational/deployment patterns.
- Aesthetician: operator ergonomics, observability clarity, configuration UX.
- Economist: resource cost, operational burden, staffing complexity.

## Writing / Narrative

- Skeptic: contradictions, unsupported claims, continuity failures.
- Architect: argument/narrative structure and information sequencing.
- Minimalist: repetition, padding, unnecessary exposition.
- Context Scout: relevant genre/context/precedent.
- Aesthetician: prose, rhythm, tone, voice, readability.
- Economist: audience fit, length versus value, production effort.

## Research / Analysis

- Skeptic: unsupported inference, confounders, missing counterevidence.
- Architect: methodology, reasoning chain, source-to-claim structure.
- Minimalist: redundant analysis, needless complexity.
- Context Scout: literature, competing explanations, external context.
- Aesthetician: clarity of charts, prose, framing, information hierarchy.
- Economist: research effort versus decision value.

## Product / UI / Visual Design

- Skeptic: broken flows, inaccessible/misleading states, edge conditions.
- Architect: hierarchy, information architecture, interaction structure.
- Minimalist: visual/interaction noise, unnecessary steps.
- Context Scout: comparable products and platform conventions.
- Aesthetician: composition, typography, polish, affordance, consistency.
- Economist: implementation cost versus user value.

## Plans / Strategy

- Skeptic: assumptions, failure scenarios, hidden dependencies.
- Architect: sequencing, ownership, dependency graph, feasibility.
- Minimalist: unnecessary workstreams and scope.
- Context Scout: prior art, external conditions, alternative strategies.
- Aesthetician: communication and stakeholder comprehension.
- Economist: expected value, opportunity cost, resource allocation.
