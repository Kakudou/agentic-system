# Sources

## Primary

- [PortSwigger Web Security Academy: File upload vulnerabilities](https://portswigger.net/web-security/file-upload) - primary learning and assessment reference for upload validation, storage, and serving risks.

## Supporting

- [OWASP File Upload Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html) - defensive controls and implementation guidance.
- [OWASP Input Validation Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Input_Validation_Cheat_Sheet.html) - general server-side validation principles.

Use current program rules as the authority for scope, permitted file types, test rate, and disclosure handling.
