# Upload Assessment Cheatsheet

## Before

- Confirm target, account, file classes, volume, rate, cleanup owner, and stop conditions.
- Select approved inert samples and define one baseline plus bounded comparisons.

## During

- Change one approved attribute at a time.
- Observe the server decision, processing state, normalized metadata, intended retrieval, and delivery headers.
- Do not use active content, bypass recipes, storage enumeration, or automation.

## Interpret

- Acceptance alone is not execution or cross-user exposure.
- A URL pattern or client-side validation alone is not a finding.
- Account for scanners, queues, caches, signed links, feature flags, and documented sharing behavior.

## Finish

- Delete, expire, or hand off each test object.
- Report the confirmed server-side control failure, its bounded impact, evidence, false-positive checks, and remediation.
