# Classification and Redaction Matrix

| Class | Typical handling category | Default handoff | Required decision |
| --- | --- | --- | --- |
| Public | Report-safe metadata | Metadata or reviewed excerpt | Confirm scope and necessity. |
| Internal | Non-public operational context | Minimum derivative or metadata | Confirm recipient and channel. |
| Confidential | Personal, private, or business-sensitive content | Metadata unless approved derivative is necessary | Confirm review, retention, and access boundary. |
| Restricted | Credentials, session material, regulated data, or uncertain high-risk content | Stop or metadata-only | Obtain documented direction before any further handling. |

Use the highest applicable class. A derivative does not lower the class until an authorized reviewer documents that decision.
