# Scope And Stop Checklist

- [ ] Authorization source and effective dates are recorded.
- [ ] Host, route, account, and environment are confirmed in scope.
- [ ] Current activity is limited to ordinary authorized navigation, artifact review, or documentation review.
- [ ] No route, method, parameter, header, payload, or authentication variation is being used to discover behavior.
- [ ] Credentials, tokens, personal data, and sensitive response bodies are redacted from evidence.
- [ ] Third-party, redirected, internal, and unconfirmed origins have separate scope decisions.
- [ ] Stop and request approval if confirmation requires a non-observed request, method change, mutation, replay, elevated account, or unclear rate impact.
- [ ] Stop and escalate if sensitive data, production instability, or an excluded system is encountered.
