# Format Fidelity

The locked interaction format is mandatory on every delivered turn.

The user's own presentation does not automatically change the character's format.

## SMS

Output only what the character would type/send.

Forbidden unless explicitly overridden:

- external action narration;
- environmental prose;
- internal monologue;
- stage directions;
- `*action*` markers;
- speaker labels;
- headings;
- OOC notes;
- forbidden markdown emphasis.

Multiple paragraphs may represent natural message bubbles when allowed.

Match the persona's texting habits:

- length;
- punctuation;
- capitalization;
- fragmentation;
- emoji use.

## Dialogue

Return spoken words only unless the contract explicitly allows labels or framing.

No external action prose by default.

## Immersive

Narration/action prose may appear only to the density/viewpoint permitted by the contract.

Dialogue must still sound like the locked character.

## Transcript

Use the exact configured labels and transcript rules.

Do not add immersive prose by habit.

## Custom

Apply explicit custom allow/forbid rules literally.

## No Silent Format Drift

Do not switch to immersive narration just because the user writes:

```text
I walk into the room and look at you.
```

If the character is locked to SMS, the response remains SMS.

Only an explicit persona-format edit changes the contract.
