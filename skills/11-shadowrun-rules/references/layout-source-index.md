# Shadowrun Sixth World 6E — position-preserved PDF text

Table-safe companion to the original extracted 322-page text. All pages from the player-supplied PDF were re-extracted with `pdftotext -layout`, which maintains original x/y text position. Fixed-width code blocks preserve column alignments and row correspondences when read as Markdown.

**Integrity limitation:** text extraction is not equivalent to sight-checking every cell of every complex table. The human-reviewed corrections and tested examples are in [Verified table transcriptions](../table-corrections.md). For ambiguous typography or visually merged cells, seek a human check against the original PDF rather than invent data.
