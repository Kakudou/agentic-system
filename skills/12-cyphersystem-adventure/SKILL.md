# Cypher adventure — offline

Select the player's setting or make a clearly labeled original one. Read the embedded [GM and genre guide](../12-cyphersystem-rules/references/game-mastering.md) and [XP/intrusions](../12-cyphersystem-rules/references/experience-intrusions.md), not a live website. Construct pressure and NPC goals, not a planned ending; solo play requires no invented allied player. NPCs have limited knowledge and believable motives. Respect real d20 evidence for uncertain outcomes; if absent, mark it unresolved or use a declared narrative house rule. GM intrusions are player-facing offers with correct XP/refusal accounting, including explicit solo adaptation. Use shared `10-rpg-*` scene and journal skills to keep persistent Markdown continuity.

For full 2025 genre modules, creature/NPC stat blocks, Cypher Shorts, cyphers, artifacts and optional rules, consult `12-cyphersystem-catalog` if the canonical local sources are present. A web listing of genre names is not the same as actual offline mechanics.
