# Integrity and Stop Checklist

## Before Admission

- [ ] Written scope and observation window cover the artifact.
- [ ] Artifact already exists from authorized work; no new action is required.
- [ ] Artifact class, source context, and minimum purpose are recorded.

## Stop and Escalate

- [ ] Stop for sensitive values, private content, unexpected state change, out-of-scope origin, or scope ambiguity.
- [ ] Stop if approved storage, access control, retention rule, or reporting channel is unavailable.
- [ ] Record only category and minimal locator when sensitive material is encountered.

## Before Handoff

- [ ] Every artifact has a stable ID, provenance, scope status, and handling class.
- [ ] Available integrity identifiers match the manifest, or the limitation is stated.
- [ ] Redacted derivatives identify their restricted original without exposing it.
- [ ] Facts, interpretations, and inconclusive items are separated.
- [ ] Recipient, channel, access restriction, and retention instruction are stated.
