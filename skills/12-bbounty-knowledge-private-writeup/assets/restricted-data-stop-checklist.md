# Restricted-Data and Stop Checklist

- Written authorization, current scope, and finding ID are present.
- Provenance, approved audience/channel, and retention/access rule are known.
- Material is already observed; no collection, replay, or validation is required.
- Sensitive content is classified before inclusion.
- The narrative needs only the admitted form: metadata, reviewed derivative, or restricted original.
- Each claim has a supporting artifact reference and stated limitation.
- Stop if scope, ownership, classification, recipient access, retention, or factual support is unclear.
- Stop if documentation would disclose personal data, credentials, session material, private content, or reproduction material beyond explicit approval.

A stop decision is the required outcome when these controls cannot be met.
