# Vendor and Data-Flow Confidence Matrix

| Dimension | Low confidence | Medium confidence | High confidence |
| --- | --- | --- | --- |
| Vendor ownership | Inferred from name or domain | One approved source identifies owner | Owner and vendor route agree |
| Flow direction | Assumed | Documented or visible once | Documented and corroborated |
| Data classification | Unknown | Owner description only | Approved redacted schema or policy corroborates |
| Identity boundary | Unclear actor or role | Documented actor | Documented and owner-confirmed decision point |
| Control coverage | Policy or label only | Configuration or log reference | Independent approved sources agree |

Use the lowest relevant confidence for the flow. Confidence measures evidence quality, not security strength.
