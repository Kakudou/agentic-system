# Static Exposure Manifest

| Field | Required record |
| --- | --- |
| Authorization | Reference and scope status |
| Source | Redacted locator and source type |
| Observation | Time and minimal boundary description |
| Classification | Suspected, potentially sensitive, confirmed exposure, or out of scope |
| Uncertainty | Ownership and validity status |
| Controls | Stop, minimization, and redaction actions |
| Handoff | Restricted recipient and status |

Never enter sensitive values, raw artifacts, reproduction details, or validation results.
