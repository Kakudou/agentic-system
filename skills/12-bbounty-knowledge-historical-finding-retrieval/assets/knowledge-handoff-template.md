# Knowledge Handoff Template

Use for a reviewed, minimized historical record. Handoff transfers context only and does not authorize access, testing, disclosure, or a claim of current applicability.

```yaml
handoff_id: string
recipient: string
approved_destination: string
record_reference: string
authorization_reference: string
historical_statement: string
relevance: supported | conditional | unsupported | unknown
confidence: low | medium | high
provenance_and_access_summary: string
privacy_status: none | redacted | restricted | stopped
limitations_and_unknowns: [string]
required_follow_up: [string]
review_status: documented | reviewed | needs-clarification | stopped
```

The recipient should acknowledge receipt, preserve handling restrictions, and decide whether to retain, revise, or reject the record.
