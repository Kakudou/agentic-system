# Scope Decision Evidence And Handoff

## Purpose

Package a scope decision so another reviewer or the program can understand its authorization basis without receiving unnecessary sensitive material.

## Preconditions

- A completed authorized, not-authorized, unresolved, or stopped decision.
- A designated recipient or documented program channel.

## Documentation Process

1. Identify the program, scope-source locator, retrieval time, proposed asset, action category, rate, and data boundary.
2. Separate source quotations, observed facts, interpretation, decision, and unanswered questions.
3. Redact credentials, tokens, personal data, customer identifiers, internal paths, and response bodies unless the program explicitly requires them.
4. State whether activity occurred. For a stopped or unresolved decision, state that no further action was taken.
5. Send only through the documented channel and retain the resulting reference or acknowledgement when available.

## Uncertainty Controls

- Evidence of asset association is not evidence of authorization.
- Do not convert a scope decision into a vulnerability claim or impact assessment.
- Mark missing acknowledgements and unanswered questions as unresolved; do not infer acceptance.

## Evidence And Handoff

Use the engagement handoff template. The minimum package is the decision, source references, restrictions, uncertainty, escalation status, and redacted evidence references.
