# Cypher character state — offline

Read [local character procedure](../12-cyphersystem-rules/references/characters-abilities.md) and [rules](../12-cyphersystem-rules/references/rules-engine.md); don't access the web. Import an existing sheet **verbatim** into a separate session copy. Track current/max Might/Speed/Intellect, each stat Edge, Effort, type/descriptor/focus/tier, abilities with exact text, trained and specialized skills, Pool expenditures, recovery-roll usage, armor, gear, cypher levels/limit and XP, injury and character arcs. NPCs normally use level, health, Armor, damage, behavior and small modifications. Make changes only from accepted action/receipt and committed event ID. Never write back to the original external character sheet without explicit player or real GM authorization.

For 2025 SRD named types, descriptors, foci, flavors, and abilities, use the local `12-cyphersystem-catalog` skill and original Markdown entries in the embedded source. Never derive mechanics from a catalog heading, name or example alone.

To create a new session-local sheet with no web dependency, fill [Cypher player sheet](assets/cypher-character-sheet.md), or [NPC sheet](assets/cypher-npc-sheet.md), using exact 2025 SRD entries and documented choices; preserve the imported original.
