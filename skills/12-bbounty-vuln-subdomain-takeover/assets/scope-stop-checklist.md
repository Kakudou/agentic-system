# Scope And Stop Checklist

- [ ] Written authorization and engagement reference are recorded.
- [ ] Source DNS name is explicitly in scope.
- [ ] Permitted sources and observation methods are known.
- [ ] Target ownership is supported independently of provider naming.
- [ ] Third-party, tenant, and provider boundaries are identified.
- [ ] Evidence has source, time, asset, and secure reference.
- [ ] No account, registration, claim, control-plane, or endpoint interaction is planned.
- [ ] Stop contact and remediation recipient are named.
- [ ] Work stops for scope conflict, ownership uncertainty, sensitive data, or unexpected third-party interaction.
