# Redaction/Stop Checklist

- [ ] The recipient and permitted evidence access path are known.
- [ ] Credentials, tokens, session material, personal data, customer content, and unrelated system data are excluded or safely redacted.
- [ ] Each redaction has a category and restricted-original access path, if applicable.
- [ ] Uncertainty, missing provenance, and scope limitations are stated plainly.
- [ ] No report wording makes unsupported access, impact, exploitability, severity, payout, or fix claims.
- [ ] No new testing, replay, reproduction, submission, or follow-up action is requested through this review.

Stop and escalate if authorization or scope is unclear, a secret or personal data is exposed, provenance is missing for a material claim, or redaction prevents meaningful authorized review.
