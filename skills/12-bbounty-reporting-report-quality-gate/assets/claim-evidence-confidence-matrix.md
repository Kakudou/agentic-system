# Claim/Evidence Confidence Matrix

| Claim ID or draft location | Claim text | Status | Evidence IDs | Boundary or limitation | Reviewer action |
| --- | --- | --- | --- | --- | --- |
|  |  | supported / bounded-inference / unsupported / withheld |  |  | retain / revise / remove / escalate |

Status meanings:

- `supported`: directly tied to admitted evidence.
- `bounded-inference`: interpretation is stated with its assumptions and limits.
- `unsupported`: lacks sufficient admitted evidence; do not present as fact.
- `withheld`: evidence or detail is restricted; record authorized access path instead.
