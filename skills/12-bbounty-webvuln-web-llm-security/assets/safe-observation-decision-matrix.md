# Safe-Observation Decision Matrix

| Condition | Permitted response | Record |
| --- | --- | --- |
| Written scope, benign fixture, and baseline are present | Compare ordinary behavior with one inert non-operative marker | Expected and observed behavior |
| Scope or permission is unclear | Stop and request clarification | Missing authorization detail |
| Observation changes only display or attribution | Repeat once under identical conditions | Redacted comparison and variability controls |
| Sensitive content appears | Stop; do not retain content; notify owner | Minimal timestamp and escalation reference |
| Data access, tool use, or state change is suggested | Stop; do not confirm through execution | Boundary and escalation reference |
| Availability or another user may be affected | Stop immediately | Impact concern and escalation reference |

Never replace a stop decision with a more complex input or repeated attempt.
