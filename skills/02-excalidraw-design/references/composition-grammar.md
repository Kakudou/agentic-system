# Composition Grammar

Use this reference to develop the three directions and architect the approved artifact.

## Structure is information

Every spatial device must encode something true:

- proximity = relationship or shared context
- containment = scope, ownership, membership, trust, or phase
- alignment = comparability or sequence
- scale = priority, abstraction, or magnitude
- direction = chronology, flow, causality, or dependency
- repetition = recurring structure
- color = stable semantic category or state

Do not add numbering, dividers, frames, labels, badges, or decorative circuitry unless they communicate real structure.

## Global and local grammars

A complex board may mix local grammars, but it must have exactly one global navigation grammar.

### Global navigation grammars

Choose one:

- **Left to right**: progression, pipeline, chronology, transformation
- **Top to bottom**: hierarchy, decomposition, authority, dependency
- **Center outward**: one core concept with domains or consequences
- **Outside inward**: context narrowing toward a mechanism or conclusion
- **Overview then detail**: map first, coordinated deep dives second
- **Spatial zones with a spine**: multiple domains connected by one shared route
- **Loop**: lifecycle, feedback, recurrence, iterative systems

State the chosen grammar in every proposal.

### Local grammars

Regions may use:

- hierarchy/tree
- process or state flow
- timeline
- swimlane
- matrix
- radial map
- layered architecture
- annotated specimen
- taxonomy
- relationship web
- callout cluster
- ledger/reference panel
- sequence strip
- before/after comparison

Each region gets one dominant local grammar. A region that needs two competing reading directions should be split.

## Hybrid composition

Mix layouts when the source contains different relationship types.

A valid hybrid composition:

- has one dominant entry point
- preserves one global reading direction
- uses shared alignment lines or a visible spine
- repeats spacing intervals
- maintains stable shape and color semantics
- uses transitions or labels to explain mode changes
- keeps cross-region connectors sparse and meaningful

An invalid hybrid composition reads like several unrelated diagrams pasted together.

When integration would create a collage, use coordinated frames instead.

## Board architecture

### One frame

Use when:

- one thesis dominates
- one reading path is natural
- content remains legible without tiny type
- cross-links are limited
- the user benefits from seeing the whole system at once

### Coordinated frames in one scene

Use when:

- an overview and deep dives serve different jobs
- the material uses incompatible local grammars
- one scene should remain navigable
- repeated entities need shared visual identity
- the user will move between frames during explanation or study

### Separate files

Use only when:

- boards must be distributed or edited independently
- dimensions become operationally unwieldy
- audiences or confidentiality differ
- the user requests separate deliverables

## Density

Design for scanning before completeness.

Use three density bands:

- **Primary**: thesis, core entities, decisive relationships
- **Secondary**: supporting detail, examples, exceptions
- **Tertiary**: notes, references, provenance, filigrane

Do not make all content equally loud.

Split or summarize when:

- body text must fall below a comfortable size
- connectors cannot avoid important labels
- more than one-third of nodes require long prose
- the reading path needs repeated verbal explanation
- an overview loses its shape under detail

## Three-direction generation

The three directions must not be skins of the same diagram.

Explore distinct answers to:

- What should the viewer understand first?
- What relationship model carries the subject?
- What can be omitted or deferred?
- Is the board explanatory, operational, exploratory, or mnemonic?
- Should the whole be visible first or discovered progressively?
- Which local grammars should coexist?

### Required pairwise difference

Every pair must differ on at least two axes:

- abstraction
- decomposition
- dominant relationship model
- reading order
- audience
- density
- exploration versus explanation
- overview versus operations

### Direction archetypes

Use these as thinking prompts, not templates:

- **System map**: reveal domains, boundaries, and cross-links
- **Narrative route**: reveal sequence, transformation, or causality
- **Operational console**: reveal actions, decisions, states, and exceptions
- **Layered anatomy**: reveal composition and dependency
- **Comparative field guide**: reveal categories, contrasts, and examples
- **Knowledge constellation**: reveal concepts and contested relationships
- **Overview/deep-dive atlas**: reveal whole and parts through coordinated frames

## Proposal quality test

Before critique, reject a direction if:

- it could fit an unrelated subject by renaming labels
- its signature device is merely decorative
- it relies on color to create structure
- it cannot explain its reading path in one sentence
- the proposed mix of layouts has no global grammar
- it includes content unsupported by the evidence ledger
- its tradeoff is vague or dishonest

## Frontend-design critique posture

When applying the loaded design skill, ask:

- What is generic here?
- Which structural device lies about the content?
- Where is visual personality detached from the subject?
- Is complexity earned?
- Is there one memorable move that improves comprehension?
- Which proposal is weakest and why?
- Does any proposal deserve replacement?

Integrate the critique. Do not merely report it.
