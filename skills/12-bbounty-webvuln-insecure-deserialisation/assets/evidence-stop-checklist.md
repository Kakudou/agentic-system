# Evidence And Stop Checklist

## Before Assessment

- [ ] Written authorization names this target and activity.
- [ ] Evidence source is within scope and can be cited without exposing secrets.
- [ ] Owner contact and escalation route are known.

## Evidence Quality

- [ ] Input location and format are recorded separately.
- [ ] Runtime/framework conclusion has a cited basis.
- [ ] Alternative explanations are documented.
- [ ] No sensitive serialized value or personal data is retained in the report.
- [ ] Impact language matches observed evidence only.

## Stop Immediately When

- [ ] Scope, ownership, or authorization is unclear.
- [ ] Confirmation would require constructing, modifying, replaying, or submitting serialized data.
- [ ] Evidence suggests execution, external interaction, file or data access, state change, or service degradation.
- [ ] A production target behaves unexpectedly or exposes sensitive material.

## Handoff

- [ ] Preserve redacted locators and timestamps.
- [ ] Notify the owner through the approved channel.
- [ ] Request a controlled remediation review rather than further probing.
