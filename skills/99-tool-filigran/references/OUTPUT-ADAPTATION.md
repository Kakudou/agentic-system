# Output Adaptation Guide

## Principle

Preserve Filigran identity without forcing every deliverable to look like the website or an application screen.

## Product UI / dashboard

Use Filigran UI first.

- canonical components;
- documented typography roles;
- spacing tokens;
- semantic colors;
- official icon library;
- theme compatibility;
- operational density driven by real tasks/data.

Avoid marketing gradients behind dense data tables or forms unless the live product system explicitly supports them.

## Marketing website / landing page

Use:

- strong hero statement;
- blue/turquoise gradient energy;
- white/dark contrast;
- generous section spacing;
- proof metrics and product imagery;
- integration/customer proof;
- clear CTA hierarchy.

Use `@filigran/ui` where it helps, but do not make a marketing page feel like an internal application simply because the component library exists.

## Internal tool

Stay closer to product UI than marketing.

Prioritize:

- canonical controls;
- compact readable density;
- clear status semantics;
- minimal decorative gradient use;
- fast task completion.

## Slide deck

Translate the brand into presentation grammar:

- white or dark-navy base;
- blue/turquoise gradient accent on title/section slides;
- large clean headlines;
- high-contrast data callouts;
- restrained card use;
- product screenshot crops;
- consistent Filigran footer/logo placement when an official asset is provided.

Do not shrink application screens until they become unreadable. Re-compose the information for slides.

## Report / PDF / document

Favor editorial readability:

- bright paper-like body pages or controlled dark section openers;
- blue/turquoise section accents;
- strong title hierarchy;
- product diagrams/screenshots where evidence is useful;
- clean tables;
- status/severity colors used semantically.

Long-form reading takes priority over dramatic gradients.

## Diagram / architecture map

Use:

- neutral structure;
- blue for primary system/flow emphasis;
- turquoise for secondary/activation emphasis;
- semantic warning/error colors only when they carry actual meaning;
- official product icons when available;
- simple readable connectors and grouping.

Clarity of relationships beats decorative brand treatment.

## Poster / social graphic

Push the corporate visual language farther:

- bold headline;
- concentrated blue/turquoise gradient field;
- one strong product/subject image;
- minimal supporting text;
- clean logo lockup from official assets.

Avoid pseudo-hacker decoration.

## Video / motion

Use premium, smooth motion:

- gradient wipes;
- diagram flow activation;
- screenshot focus/zoom;
- typography reveal;
- integration/logo movement;
- restrained parallax.

Avoid glitch/strobe unless a specific campaign concept explicitly calls for it.

## GIF / short loop

Create a clean resting state, a single interaction/story beat, and a stable return. The motion should explain or emphasize, not merely animate the brand.

## Non-visual / constrained output

Carry brand through tone and structure:

- concise headings;
- signal-over-noise organization;
- clear evidence hierarchy;
- direct calls to action;
- terminology aligned with Filigran's public product language.
