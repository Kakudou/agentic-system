# Scope and Stop Checklist

- [ ] Asset and environment are explicitly in scope.
- [ ] Identity, tenant, account, or test data is authorized.
- [ ] Proposed observation is necessary for the documented claim.
- [ ] No third-party data, secrets, or production state will be accessed or changed.
- [ ] The next action is allowed by program rules and rate limits.
- [ ] Stop if scope, consent, effect, or data handling is unclear.
- [ ] Record the limitation and request program-side validation when stopped.
