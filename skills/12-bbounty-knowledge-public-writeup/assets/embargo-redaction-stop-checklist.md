# Embargo, Redaction, And Stop Checklist

- [ ] Public disclosure authorization is explicit, current, and referenced.
- [ ] Embargo status, release condition, and approved scope are recorded.
- [ ] No active embargo, unresolved remediation condition, or instruction conflict remains.
- [ ] Each retained claim has public-admissible evidence and bounded wording.
- [ ] Identifiers, secrets, personal data, private correspondence, and internal details are removed.
- [ ] Images, metadata, filenames, links, and captions received the same redaction review.
- [ ] Attribution is explicitly permitted and uncertainty is stated.
- [ ] No material provides operationally actionable exploitation guidance.
- [ ] Required reviewers and unresolved questions are listed.

Stop and mark the package `blocked` if any authorization, embargo, evidence, or redaction item cannot be confirmed.
