# Scope And Stop Checklist

## Before Modeling

- [ ] Written authorization reference is recorded.
- [ ] In-scope assets and exclusions are recorded.
- [ ] Each evidence item has source, locator, time, and collection context.
- [ ] Recipient and approved handling channel are known.

## Stop And Escalate

- [ ] Stop if asset ownership or scope membership is ambiguous.
- [ ] Stop if evidence provenance, integrity, or collection authority is missing.
- [ ] Stop if material includes secrets, personal data, or restricted information without an approved handling path.
- [ ] Stop if synthesis would require collection, probing, testing, or a vulnerability conclusion.
- [ ] Stop if a conflict cannot be represented without unsupported resolution.

## Before Handoff

- [ ] Every material claim cites evidence IDs and confidence.
- [ ] Unknowns, exclusions, and conflicts are visible.
- [ ] Review indicators use neutral observation language.
- [ ] The handoff states that it makes no vulnerability claim.
