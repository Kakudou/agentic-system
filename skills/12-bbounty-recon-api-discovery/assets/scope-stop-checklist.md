# Scope And Stop Checklist

- [ ] Written authorization covers the exact host, API product, identity, and observation source.
- [ ] Rate limit, time window, evidence policy, and stop contact are recorded.
- [ ] Each documentation artifact is program-provided or linked from an approved source.
- [ ] Each client observation is part of an approved ordinary, non-mutating flow.
- [ ] No endpoint, version path, parameter, schema, service, or protocol is being guessed or enumerated.
- [ ] No request is altered, replayed, introspected, authenticated, or automated beyond explicit approval.
- [ ] Stop for scope ambiguity, out-of-scope redirect/call, login, sensitive exposure, state change, rate limiting, instability, or policy conflict.
- [ ] Handoff distinguishes observation, confidence, limitation, and requested follow-up.
