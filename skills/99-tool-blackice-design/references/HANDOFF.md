# Handoff to `98-external-frontend-design`

## Purpose

This skill defines the **visual identity**. `98-external-frontend-design` owns the design-thinking and execution loop.

When handing off, do not prescribe the output format unless the user did. Instead pass a compact art-direction brief based on the request.

## Required handoff fields

Construct the equivalent of the following in your working context:

```text
SUBJECT
- What is being designed?
- Who is it for?
- What is its single most important job?

DELIVERABLE
- User-requested medium/format, if specified.
- If unspecified, choose/recommend the medium based on the actual goal.
- Constraints: platform, dimensions, tooling, file format, duration, print/digital, etc.

BLACK ICE VISUAL LANGUAGE
- Dominant structural color: #003B6F.
- Live/active accent: #00FF66.
- Warning/anomaly accent: #FF8C00.
- Dark neutral surfaces: #04080D / #0A0F1C / #1A2230.
- Primary readable text: #C9D1D9 / #F4F7FA.
- Angular, clipped, asymmetric technical framing.
- Condensed display + readable body + utility mono when typography supports roles.
- Neon used as punctuation, not wallpaper.
- Supplied geometric logo from assets/ when branding is appropriate.
- Mandatory topmost artifact/glitch layer.

GLITCH INTENSITY
- Choose G1–G4 from references/GLITCH-LAYER.md.
- Default G2.
- Include reduced/static fallback where relevant.

SUBJECT-SPECIFIC SIGNATURE
- One memorable idea derived from the actual subject.
- Must not simply be “more glitch.”

AVOID
- Generic SaaS cards.
- rounded-everything UI.
- generic black+green hacker cliché.
- magenta/cyan synthwave takeover.
- glow everywhere.
- fake telemetry.
- copied Cyberpunk 2077 logos/screens/type treatments.
```

## Relationship with the dependency skill

The dependency skill explicitly values subject grounding, deliberate typography, meaningful structure, one signature idea, motion with purpose, and self-critique. Preserve those rules.

Where the two skills interact:

- This skill fixes the broad brand palette and visual grammar.
- The dependency chooses the exact composition, fonts, signature, writing, spacing, and artifact-specific implementation.
- User instructions override both.
- Accessibility and usability override decorative effects.

## Final critique questions

Ask before delivery:

1. Does the artifact feel made for this subject rather than as a reusable cyberpunk template?
2. Is `#003B6F` structurally dominant without swallowing the whole canvas?
3. Are green and orange semantically meaningful?
4. Is the top glitch layer clearly present yet non-destructive?
5. Is the logo crisp and correctly used?
6. Is the result recognizably Black Ice even if the glitch layer is muted?
7. Did the dependency skill's originality/self-critique process alter anything for the better?
