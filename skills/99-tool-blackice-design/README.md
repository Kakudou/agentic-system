# 99-blackice-design-language

An Agent Skills-compatible art-direction overlay for Kakudou's Black Ice visual language.

## Install

Place this directory next to:

```text
skills/
├── 98-external-frontend-design/
│   └── SKILL.md
└── 99-blackice-design-language/
    ├── SKILL.md
    ├── references/
    └── assets/
```

The skill deliberately does **not** hard-code an output medium. It supplies the design system and requires `98-external-frontend-design` for the subject-aware design/execution process.

## Core palette

- `#003B6F` — dominant TARDIS blue structure
- `#00FF66` — lightsaber green live/active signal
- `#FF8C00` — lightsaber orange warning/heat

A top-layer artifact/glitch treatment is mandatory in every visual output, animated or static depending on the medium.
